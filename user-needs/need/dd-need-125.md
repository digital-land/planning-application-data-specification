name: Publish specified planning data as open data
statement: >
  As a planning authority, I need to know which planning application data must
  be published as open data so that I can meet publication requirements
  consistently while protecting information that cannot lawfully be made
  public.
actors:
  - planning-authority
scope: in
themes:
  - open-data
  - transparency
  - compliance
source:
  - type: legislation
    notes: Levelling-up and Regeneration Act 2023 section 86 provides a power to require specified planning data to be made publicly available under an approved open licence, subject to obligations of confidence and other restrictions on publication.
variations:
  - dd-need-100
  - dd-need-126
next_step:
notes: |
  This need concerns a specified subset of planning application data. It does not mean that the complete planning register, submitted application data or validated application data must be published openly.
