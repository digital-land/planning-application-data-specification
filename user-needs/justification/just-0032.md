The planning-permission-timeline dataset lets each timeline event record what happened, when it happened and optional human-readable context. This supports a clear account of many key stages and helps users understand progress, repeated events, delays and changes in route or status.

The need is partially satisfied because the event codelist does not yet cover every event implied by a complete post-submission timeline. In particular, it does not currently include structured events for amendments or milestones in completing a legal agreement. Optional notes can provide context, but should not substitute for standard event types where consistent tracking is needed.
