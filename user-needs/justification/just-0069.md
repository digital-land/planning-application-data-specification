The `officer-name` field lets a planning application record identify the case officer currently responsible for handling the application.

This partly satisfies `dd-need-115` because it records current case ownership, but the field is not included in the national public view. Some local planning authorities publish case officer names on their public registers, but this does not yet establish a need to make named officers available as national open data. The publication need and data protection considerations should be reviewed before that boundary changes.

This partly satisfies `dd-need-128` because current assignments can support a view of practitioner workloads. The specification does not record when an assignment began or ended, or preserve changes in assignment, so it cannot support assignment history, handovers or workload analysis over time.
