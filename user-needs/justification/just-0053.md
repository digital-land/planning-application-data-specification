The `planning-performance-agreement` field records whether an application was subject to a Planning Performance Agreement for performance reporting purposes.

The `time-extension-agreed` value in the `permission-process-event` codelist lets the planning permission timeline record when an Extension of Time was agreed.

Together, these fields let analysts identify applications using Planning
Performance Agreements and Extensions of Time, and let policy users examine
where those arrangements are used. They partially satisfy `need-ps-027` and
`need-ps-031` because the specification does not yet identify applications using
the EIA timetable.
