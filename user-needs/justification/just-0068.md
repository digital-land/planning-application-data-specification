The optional `notes` field lets a data producer provide relevant context about a planning application when that information is useful but is not represented elsewhere in the dataset.

This may include qualifications, unusual circumstances, source limitations or transitional information encountered while assembling the record. For example, a note can explain that the completed application form was unavailable from the online public register and that the record was assembled from other published evidence.

The field is included in the national public view because it provides context about the published planning application record. It must not be used to publish sensitive information. Where the same kind of information appears repeatedly and becomes important for filtering, validation or comparison, it should be considered for structured modelling.
