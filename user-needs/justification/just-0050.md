The `planning-performance-agreement` field classifies whether an application was subject to a Planning Performance Agreement for performance reporting purposes.

This supports PS1 and PS2 reporting, which asks for counts of decisions where the application was subject to a Planning Performance Agreement.

The specification uses a narrow classification to report whether an agreement applied, did not apply or cannot be established. This leaves room for more precise values if further needs are verified, without assuming that we need to model the agreement itself. Planning Performance Agreements are normally agreed before an application is submitted, do not have to be published and may not be available as public documents. There is not yet evidence for modelling the agreement, timetable, fee, publication status or lifecycle more broadly.
