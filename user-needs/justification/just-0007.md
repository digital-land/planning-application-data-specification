Capturing `received-date` alongside the application `reference` provides the statutory record of when each application arrived, enabling authorities to evidence compliance with procedural duties.

The same fields let wider planning-system users distinguish receipt by the planning authority from the applicant's submission and the authority's later validation activity. This establishes when the authority's end-to-end handling of the application began.
