The `invalid-from` event records when an application was treated as invalid and
links that event to the application. This lets policy users count invalid
applications, compare patterns over time and identify changes that warrant
further investigation.

The event does not explain why an application was invalid, but that information
is not required to satisfy this frequency-monitoring need.
