The `advertising` value in `application-types` identifies advertisement applications.

Linking a decision notice to the planning application and recording `decision` and `decision-date` lets users track the outcomes of advertisement applications and when those decisions were made.

This only partially satisfies the need because the planning application data does not provide structured information about the advertisement characteristics needed to analyse effects on visual amenity and local character.
