The `pip` and `technical-details-consent` values in `application-types` identify Permission in Principle applications and Technical Details Consent applications.

The `linked-applications` field allows a Technical Details Consent application to reference the earlier Permission in Principle application it follows. Linking decision notices to those applications and recording `decision` and `decision-date` lets users track their progress and outcomes.

This partially supports tracking progress from Permission in Principle to an implementable permission. It is not marked as full because these fields do not reliably quantify how much planned development is progressing through the linked applications.
