# Class Q agricultural tenancies

Current agricultural tenancy consent and agreements about agricultural need following recent tenancy termination for a prior approval change of use from agricultural buildings to dwellinghouses.

**Class Q agricultural tenancies module**

| reference | name | description | only for application | requirement | notes |
| --- | --- | --- | --- | --- | --- |
| agricultural-tenants | Agricultural tenants | Whether the site is currently occupied under any agricultural tenancy agreements. |  | MUST |  |
| tenancy-parties-consent | Consent of all tenancy parties | Whether all parties to the agricultural tenancy agreements have consented to the proposed change of use. |  | MUST | Required when agricultural tenancy agreements exist. Consent must cover all parties to all relevant agreements, not only the tenants. |
| cls-q-tenancy-terminated | Agricultural tenancy terminated for proposed change of use | Whether any agricultural tenancy agreements have been terminated in the year before development is proposed to begin for the purpose of carrying out the proposed change of use. |  | MUST |  |
| cls-q-agri-use-not-required | Agreement that site is no longer required for agricultural use | Whether all parties to all relevant terminated agricultural tenancy agreements have agreed that the site is no longer required for agricultural use. |  | MUST |  |
