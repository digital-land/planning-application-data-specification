# Class Q current agricultural unit eligibility

Agricultural unit membership history for a prior approval change of use from agricultural buildings to dwellinghouses where the site is currently part of an established agricultural unit.

**Class Q current agricultural unit eligibility module**

| reference | name | description | only for application | requirement | notes |
| --- | --- | --- | --- | --- | --- |
| cls-q-unit-on-2023-07-24 | Agricultural unit on 24 July 2023 | Whether the site was part of an established agricultural unit on 24 July 2023. |  | MAY | Rule: is a MUST if `cls-q-eligib.cls-q-current-agri-unit` is `True` |
| cls-q-unit-10-years | Agricultural unit membership for 10 years | Whether the site will have been part of the established agricultural unit for at least 10 years before development begins. |  | MUST | Select from the **yes-no-not-applicable** enum |
