# Class Q dwellinghouses and floor space

Proposed net dwelling increase, individual dwelling size and cumulative dwelling counts and floor space for prior approval of agricultural buildings to dwellinghouses.

**Class Q dwellinghouses and floor space module**

| reference | name | description | only for application | requirement | notes |
| --- | --- | --- | --- | --- | --- |
| net-dwellings-increase | Net increase in dwellings | The number of dwellinghouses proposed by the development additional to the number on the site immediately prior to development. |  | MUST |  |
| single-dwelling-over-150sqm | Single proposed dwelling over 150 square metres | Whether the floor space of any single proposed dwellinghouse exceeds 150 square metres. |  | MUST |  |
| cls-q-previous-dwellings | Dwellinghouses previously created under Class Q | The number of dwellinghouses previously created under Class Q on the established or former agricultural unit. |  | MUST |  |
| floorspace | Floorspace | Total combined floor space, in square metres, previously and now proposed to be changed to dwellinghouses under Class Q on this established or former agricultural unit. |  | MUST |  |
