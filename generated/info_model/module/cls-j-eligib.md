# Class J non-domestic roof solar eligibility

Roof projection, edge distance, generation capacity and location eligibility information for roof-mounted solar photovoltaic equipment on non-domestic buildings.

**Class J non-domestic roof solar eligibility module**

| reference | name | description | only for application | requirement | notes |
| --- | --- | --- | --- | --- | --- |
| roof-pv-exceeds-proj | Roof PV exceeds projection limit | Whether any proposed solar photovoltaic equipment exceeds the applicable projection or height limit for the roof. |  | MUST |  |
| roof-pv-within-edge | Roof PV within roof edge distance | Whether any part of the solar photovoltaic equipment would come within 1 metre of the external edge of the roof. |  | MUST |  |
| roof-pv-less-50kw | Roof PV capacity at most 50 kW | Whether the total electrical generation capacity of equipment installed on the building under permitted development rights, including previous installations and this proposal, would be no more than 50 kilowatts. |  | MUST |  |
| has-location-restriction | Has location restriction | Whether the solar photovoltaic equipment would be installed on any part of the roof of a building that is a scheduled monument (or the site contains one), or a listed building (or within the curtilage of a listed building). |  | MUST | Use the Class J question and advice in this module body. |
