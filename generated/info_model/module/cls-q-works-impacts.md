# Class Q works, impacts and risks

Proposed development, building works and impact and risk details for prior approval of agricultural buildings to dwellinghouses.

**Class Q works, impacts and risks module**

| reference | name | description | only for application | requirement | notes |
| --- | --- | --- | --- | --- | --- |
| proposal-description | Proposal description | Description of the proposed development, including the siting and location of the building or buildings. |  | MUST |  |
| natural-light-details | Natural light details | Details of the provision of adequate natural light in all habitable rooms of the proposed dwellinghouses. |  | MUST |  |
| buildings-extended | Buildings extended | Whether the buildings will be extended as part of the proposed development. |  | MUST |  |
| impact-on-amenity | Impact on amenity | Details of any impact of the proposed extension on the amenity of adjoining premises. |  | MUST |  |
| cls-q-building-works-required | Building works required for change of use | Whether associated building works or other operations are required to convert the buildings to dwellinghouses under Class Q. |  | MUST | Related to proposal-incl-building-operations, which records whether operations are included in a proposal. This field records whether the specified conversion works are required. The fields could potentially be combined following review of their meanings and uses; they remain distinct for now. |
| design-details | Design details | Details of the design and external appearance of the buildings for the associated building works or other operations, including partial demolition. |  | MUST |  |
| transport-impacts | Transport impacts | Details of transport and highways impacts of the proposed development and how they will be mitigated. |  | MUST |  |
| noise-impacts | Noise impacts | Details of noise impacts associated with the proposed development and how they will be mitigated. |  | MUST |  |
| contamination-risks | Contamination risks | Details of contamination risks associated with the proposed development and how they will be mitigated. |  | MUST |  |
| flooding-risks | Flooding risks | Details of flooding risks associated with the proposed development and how they will be mitigated. |  | MUST | For Class Q applications, this question carries a conditional requirement for a flood risk assessment document, specified in the cho-agri-to-dwh application definition. That condition concerns the document, not whether the flooding-risk narrative is required. Section 7 does not collect structured answers establishing the trigger facts. |
