The Class Q source question is:

Does the new building have suitable access to a public highway?

This records suitability of access, whether existing or proposed. It does not ask whether a new or altered access is proposed.

Source: section 4a of the [Class Q application form, version ECAB 2024.2](https://ecab.planningportal.co.uk/uploads/appPDF/E2734Form044_england_en.pdf).
