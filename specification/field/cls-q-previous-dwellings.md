How many dwellinghouses have previously been created under this permitted development right on this established/former agricultural unit:

Record 0 if none have previously been created. This is the count created under Class Q, not the total number of existing dwellinghouses.

Source: section 6 of the [prior approval application form for agricultural buildings to dwellinghouses (Class Q), version ECAB 2024.2](https://ecab.planningportal.co.uk/uploads/appPDF/E2734Form044_england_en.pdf).
