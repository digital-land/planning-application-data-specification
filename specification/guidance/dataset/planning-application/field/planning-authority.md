### How to use it

Use the identifier for the planning authority that received the application.

Find the authority in the [`planning-authority` codelist](https://github.com/digital-land/planning-application-data-specification/blob/main/data/codelist/planning-authority.csv) and use its reference, rather than its name or a locally created code.

For example, use `local-authority:LDS` for Leeds City Council.
