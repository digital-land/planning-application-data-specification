### How to use it

Use a short name that people can recognise and use when discussing the site.

Use an established site, building or development name. Omit `name` where there
is no meaningful established name. Use `address-text` to provide a readable
description of an unaddressed site.

### Examples

#### Good

- `Former Riverside Mill`
- `Units 4 to 8, Beacon Industrial Estate`

#### Avoid

- `Site 1`
- a site or planning application reference
- the full description of the proposed development
